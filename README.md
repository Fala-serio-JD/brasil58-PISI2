🧬 Algoritmo Genético: Caixeiro Viajante (brazil58.tsp)Este projeto consiste em uma solução estocástica baseada em Algoritmo Genético (A.G.) para resolver o Problema do Caixeiro Viajante (Traveling Salesperson Problem - TSP), utilizando o dataset oficial brazil58.tsp (58 cidades brasileiras).🏆 STATUS DO PROJETO: ÓTIMO GLOBAL ALCANÇADO! 🏆
O objetivo principal de encontrar o ciclo hamiltoniano de menor custo computacional foi cumprido com excelência, atingindo a melhor solução matemática conhecida de 25395 (0.00% de erro).👥 Divisão de Responsabilidades e CréditosA arquitetura do projeto foi estruturada seguindo o princípio da Responsabilidade Única (Clean Code), onde cada módulo do sistema desempenha uma função bem definida:🏛️ Arquitetura Geral do Sistema: Daniel Erick e Jezreel David🔬 Módulo de Automação de Testes e Análise: Jezreel David🧠 Algoritmo Genético e Operadores (OX / INV): Lucas Gabriel📏 Funções de Aptidão, Custo e Leitura de Dados: Richard Carmo📁 Arquitetura do RepositórioA estrutura de arquivos do projeto está organizada da seguinte forma:brasil58-PISI2/

⚙️ Detalhamento dos Módulos🛠️ 1. Módulo src/app/ (Engenharia do A.G.)main.py: Gerencia o ciclo de vida do algoritmo genético. Inicializa a população aleatória, coordena a seleção por torneio ($k=3$), aplica cruzamento e mutação, preserva a elite (elite=2) e encerra após a contagem de gerações definida.OX.py (Order Crossover): Operador especializado para problemas permutacionais. Seleciona duas posições aleatórias no Pai 1 para criar uma fatia preservada no filho e preenche as demais posições com a ordem relativa do Pai 2, evitando duplicidade de cidades.INV.py (Inversion Mutation): Realiza a mutação sorteando dois pontos na rota e invertendo a ordem do subintervalo. Mantém a validade da permutação enquanto introduz diversidade genética.custo.py & aptidao.py: Avaliam o desempenho de cada rota. O custo soma todas as arestas consecutivas $(c_i, c_{i+1})$ e adiciona a aresta de retorno $(c_n, c_1)$.📄 2. Módulo src/docs/ (Tratamento de Dados)lerBrasil58.py: Lê a matriz de arestas em formato triangular superior (edgesbrasil58.tsp) e constrói um dicionário de adjacência bidirecional (i, j) -> peso, permitindo consultas de distância em tempo constante $\mathcal{O}(1)$.🧪 3. Módulo src/testes/ (Automação e Análise)automação_teste.py: Executa uma bateria de simulações configuradas em 4 cenários distintos.Utiliza a classe SaidaDuplicada para redirecionar o stdout simultaneamente para o terminal e para arquivos de relatório numerados sequencialmente (relatorio1.txt, relatorio2.txt, etc.).Executa a limpeza automática de diretórios __pycache__ via shutil.rmtree ao final de cada bateria.📊 Análise dos Resultados e BenchmarksA automação de testes avaliou 4 cenários paramétricos com 5 repetições independentes cada.
